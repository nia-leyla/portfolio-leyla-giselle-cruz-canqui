# 🧠 Análise de Viés em IA - Teachable Machine

## 📝 Descrição do Projeto
* Este projeto foi desenvolvido como parte do **Laboratório de Classificação Visual (Experiência 02)**[cite: 1]. [cite_start]O objetivo central foi investigar como a escolha limitada de dados durante o treinamento de uma IA pode resultar em **vieses algorítmicos** e classificações imprecisas[cite: 13, 16].

* A análise focou na tentativa de classificar traços de personalidade — **"Introvertido"** e **"Extrovertido"** — a partir de sinais visuais[cite: 18]. [cite_start]O experimento demonstrou que o modelo tende a aprender padrões superficiais, como expressões faciais e posturas, em vez de características psicológicas reais[cite: 14, 19].

## 🚀 Tecnologias Utilizadas
* **Ferramenta:** [Teachable Machine](https://teachablemachine.withgoogle.com/) (Google) [cite: 1, 13]
* **Tecnologia:** Inteligência Artificial, Visão Computacional e Classificação de Dados [cite: 1]

## 📊 Resultados e Aprendizados
* **Identificação de Viés:** O modelo apresentou falhas ao atribuir resultados que não correspondem à percepção real do indivíduo, baseando-se em estereótipos[cite: 16, 20].
* **Consequência Social:** Percebeu-se que rótulos imprecisos em contextos profissionais ou sociais podem limitar oportunidades e reforçar julgamentos simplistas[cite: 23, 24].
* **Ações Mitigadoras:** A importância da **revisão humana** na seleção e validação dos dados para garantir que diferentes formas de comportamento sejam representadas de maneira justa[cite: 26, 27, 28].
