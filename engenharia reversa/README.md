# 🤖 Máquina Genial - Engenharia Reversa com IA
 
## 📝 Descrição do Projeto
Este projeto foi desenvolvido através da **Engenharia Reversa Assistida por IA** utilizando o Google AI Studio. O objetivo foi reconstruir um chatbot de dilemas morais a partir da análise apenas da interface externa, sem acesso ao código-fonte original.

O processo consistiu em analisar as funcionalidades, mapear a lógica de negócio e descrever as interações para o Gemini atuar como desenvolvedor Full-Stack. O resultado é um chatbot funcional que apresenta dilemas éticos ao usuário e gera respostas baseadas em IA generativa, demonstrando como a engenharia de prompt pode substituir a codificação manual.

Desenvolvido como parte da disciplina **Engenharia de Prompt e Aplicações em IA - Unicid (2026.1)**.

**🔗 Link do App:** [Acessar Máquina Genial](https://ai.studio/apps/7812f6b3-1089-4252-94e4-74dbb5abcfe9)

## 🚀 Tecnologias Utilizadas
* **Plataforma:** Google AI Studio
* **Modelo de IA:** Gemini
* **Técnica:** Engenharia de Prompt + Engenharia Reversa
* **Linguagens Geradas:** HTML, CSS, JavaScript
* **Conceito Aplicado:** Desenvolvimento Assistido por IA
 
## 📊 Resultados e Aprendizados
O projeto demonstrou na prática a mudança de paradigma no desenvolvimento de software.

* **100% do código gerado por IA** a partir de descrição funcional, sem escrita manual de sintaxe.
* **Validação por Iteração:** Aprendi a refinar instruções no AI Studio até o comportamento ficar idêntico à referência.
* **Decomposição Lógica:** Desenvolvi a habilidade de quebrar uma interface em componentes e regras de negócio para "explicar" para a IA.
* **Pensamento Crítico:** Entendi a importância de testar edge cases e validar o output da IA, em vez de aceitar a primeira resposta.
