# 🧠 Sistema de Gestão de Orçamentos com IA no Bubble

## 📝 Descrição do Projeto
Este projeto foi desenvolvido na plataforma **Bubble** com o objetivo de criar uma aplicação web para **gestão de orçamentos**, permitindo cadastrar, editar e acompanhar propostas comerciais de forma simples, organizada e eficiente.

A aplicação possibilita o registro de informações como nome do cliente, descrição do serviço, valor estimado, status do orçamento, data de criação e observações adicionais.

O desenvolvimento utilizou a **Inteligência Artificial do Bubble** como acelerador para a criação da estrutura inicial da aplicação, incluindo interface, banco de dados e workflows.

🔗 **Acesse a aplicação:**  
https://katapaza13-35041.bubbleapps.io/version-test?debug_mode=true

## 🚀 Tecnologias Utilizadas

- **Plataforma No-Code:** Bubble
- **Banco de Dados:** Database nativo do Bubble
- **Inteligência Artificial:** Bubble AI
- **Conceitos Aplicados:** Engenharia de Software, Modelagem de Dados, Governança e Segurança

---

## 🗂️ Estrutura de Dados

### 📌 Tipo de Dado: Orçamento

| Campo        | Tipo   | Descrição |
|------------|------|------|
| Cliente | Texto | Nome do cliente |
| Serviço | Texto | Descrição do serviço ou produto |
| Valor | Número | Valor estimado do orçamento |
| Status | Texto | Situação do orçamento (Pendente, Aprovado, Rejeitado) |
| Data | Data | Data de criação |
| Observações | Texto | Informações adicionais |
